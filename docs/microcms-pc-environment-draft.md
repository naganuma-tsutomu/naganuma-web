## 3台のProxmoxノード

自宅で常時利用するサービスや検証環境は、3台のProxmoxノードへ分散しています。メインノードと、省電力な補助ノードを組み合わせ、それぞれの特徴に合ったワークロードを配置しています。

### `proxmox-main`：ホームラボの中心

`proxmox-main`は、クラスタ内で最も処理能力とメモリ容量に余裕があるメインノードです。ストレージ、メディア、開発、自動化に関係するサービスを中心に動かしています。

| 項目 | 構成 |
| --- | --- |
| 本体 | 自作PC |
| CPU | AMD Ryzen 5 5600G（6コア／12スレッド） |
| メモリ | 16×4 64GiB |
| GPU | NVIDIA GeForce RTX 3060 |
| システムディスク | NVMe m.2 SSD 500GB |
| データディスク | ZFSプール（【台数・容量・構成】） |
| NIC | 1GbE／2.5GbE |
| 主な用途 | ストレージ、メディア、開発、自動化 |

NextcloudやJellyfinなど、容量が増えやすいサービスはZFS側へ配置しています。  
GPUはHermes Agentやollama、ComfyUIなどに利用しています。

`proxmox-2nd`は、比較的負荷が小さく、常時動かしたいサービスを担当しています。メインノードの保守中でも監視環境を残しやすいよう、監視やダッシュボードを別ノードへ分けています。

## 用途ごとにPCを分ける理由

台数を増やすこと自体が目的ではなく、次のように役割を分離することを重視しています。

- **普段の作業を止めない**：メインPCでは大きな検証をしない
- **常時稼働と検証を分ける**：サーバー上のサービスと実験環境を分離する
- **バックアップを独立させる**：仮想化ホストとは別のPBSへ保存する
- **実機で確認する**：Linuxやハードウェア固有の挙動を専用PCで試す
- **故障を切り分けやすくする**：まな板PCでパーツ単位の確認を行う

仮想マシンで済むものはProxmox上へ集約し、実機が必要な検証だけ専用PCを使う、という方針です。
